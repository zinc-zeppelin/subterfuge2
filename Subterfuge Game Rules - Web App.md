\# Subterfuge

\#\# Game Overview

Subterfuge is a strategic espionage game where players navigate deception to achieve victory. Teams must guess the contents of a codebook with help from secret moles embedded in each team. Players build alliances, identify moles, and gather intelligence while protecting their own secrets.

\#\# Game Objective

Each team must correctly guess as many secret code words as possible from the codebook while preventing the opposing team from discovering their own codes.

\#\# Game Setup

\#\#\# Player Assignment

1\. The app automatically assigns each player one of the following roles:

   \- Red Team Agent (Regular)

   \- Red Team Spymaster

   \- Red Team Mole (secretly working for Blue Team)

   \- Blue Team Agent (Regular)

   \- Blue Team Spymaster

   \- Blue Team Mole (secretly working for Red Team)

2\. Players are only shown their own role and team color.

3\. Moles know they are moles and which team they are actually working for.

4\. Spymasters have special endgame responsibilities.

\#\#\# Codebook Creation

1\. Each player submits a single-word noun as their secret code word.

2\. The system stores these words in the digital "codebook."

3\. Each player only knows their own code word initially.

\#\#\# Team Formation

1\. Players are shown only their team (Red or Blue).

2\. Moles appear to be on one team but are secretly working for the opposing team.

3\. Mole identities are hidden until after both teams give their verdicts.

\#\# Gameplay

\#\#\# Communication System

1\. The app provides the following communication channels:

   \- Public Chat: Visible to all players

   \- Red Team Chat: Visible only to apparent Red Team members

   \- Blue Team Chat: Visible only to apparent Blue Team members

   \- Private Messaging: One-on-one communication between any two players

2\. Players use these channels to:

   \- Share information about code words

   \- Build trust

   \- Build alliances

   \- Identify moles

   \- Share and gather intelligence

\#\#\# Mole Operations

1\. Moles must appear loyal to their apparent team while secretly helping their actual team.

2\. Moles can reveal their identity to selected players by using a secure verification system in the app.

3\. Teams can attempt to identify the opposing team's mole through careful observation and strategic information sharing.

\#\# Endgame

\#\#\# Team Verdict Submission

1\. After the predetermined game time expires, each team submits their "verdict" \- their best guess of all code words in the codebook.

2\. If a team cannot agree on their verdict, the team's Spymaster makes the final decision.

\#\#\# Scoring

1\. The system automatically scores each team's verdict:

   \- \+1 point for each correctly guessed code word

   \- \-1 point for each incorrect guess

2\. The team with the highest score wins.

3\. In case of a tie, each team can guess who the moles were (optional tiebreaker).

\#\# Game Variants

\#\#\# Timed Mode

\- Limited gameplay duration presets (e.g., 4 hours, 12 hours, or 24 hours suggested with input box for any integer amount)

\- Progress bar shows remaining time

\#\#\# Tournament Mode

\- Multiple rounds with rotating team compositions

\- Leaderboard tracking individual and team performance

\#\# Technical Implementation

\#\#\# User Interface

1\. \*\*Lobby Screen\*\*:

   \- Game setup options

   \- Player roster

   \- Ready status indicators

2\. \*\*Main Game Interface\*\*:

   \- Team color indicator

   \- Role identifier

   \- Communication panel with tabs for different channels

   \- Code word journal for tracking information

   \- Timer display

3\. \*\*Player Actions\*\*:

   \- Share code (with selected players or channels)

   \- Verify mole identity (secure system)

   \- Vote on team decisions

\#\#\# Game Flow

1\. \*\*Setup Phase\*\*:

   \- Players join lobby

   \- System assigns roles

   \- Players submit code words

   \- Game begins

2\. \*\*Main Phase\*\*:

   \- Timer starts

   \- Communication channels open

   \- Intelligence gathering begins

3\. \*\*Verdict Phase\*\*:

   \- Timer expires

   \- Teams submit verdicts

   \- System calculates scores

   \- Winner announced

4\. \*\*Reveal Phase\*\*:

   \- All roles and code words revealed

   \- Game statistics displayed

   \- Option to play again

\#\#\# Security Features

1\. \*\*Role Verification\*\*:

   \- Secure method for moles to prove identity

   \- Authentication for private messages

   \- Protection against screen sharing/peeking

2\. \*\*Anti-Cheating Measures\*\*:

   \- Automatic detection of multiple accounts

   \- Rate limiting on communications

   \- Reporting system for rule violations
